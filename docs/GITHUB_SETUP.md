# Publishing this project to GitHub

1. Edit `LICENSE` (replace YOUR NAME) and `README.md` (replace YOUR-USERNAME).
2. Create an empty repository on github.com named `clipping-station` (no README, no .gitignore, no license).
3. In this folder run:

```bash
git init
git add .
git commit -m "Initial commit: Clipping Station"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/clipping-station.git
git push -u origin main
```

Suggested repository topics: `clipper`, `twitch`, `streamlink`, `ffmpeg`, `shorts`, `reels`, `tiktok`, `python`.
